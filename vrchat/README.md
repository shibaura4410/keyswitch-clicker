# キースイッチ・クラッシャー(VRChat ワールド版)

ブラウザ版(`index.html`)を VRChat のワールドに移したものです。部屋の中央にある大きなキースイッチを叩いて壊し、左右の看板で工具を買ったり記録を見たりします。

- 1 人ずつ別々に進みます。同じワールドにいても、ほかの人の進み具合は見えません。
- 進み具合は VRChat の保存機能(PlayerData)でプレイヤーごとに残り、次に入ったときに続きから遊べます。
- 工具 10 種・自動破壊 12 種・急所ねらい・強化 160 個・実績 122 個・軸 10 種・金のキー・周回・まとめ買い・統計・音量を、ブラウザ版と同じ数字で入れてあります。

## まだ Unity で動かしていません

このフォルダーは Unity のない環境で作りました。次のことは確かめてあります。

- ゲームの計算がブラウザ版と一致すること(同じ操作を両方に流して比べる試験。下の「確かめ方」)
- スクリプトが呼ぶ Unity・VRChat の命令が、VRChat SDK 3.9.0 の Udon で使えるものだけであること
- スクリプトと組み立てスクリプトが、SDK 3.9.0 の本物のライブラリを相手に型の検査を通ること

次のことは Unity を開かないと確かめられないので、まだです。

- UdonSharp のコンパイルが通ること(UdonSharp だけの文法の制限に触れていないか)
- 組み立てたワールドの見た目(看板の文字の大きさや位置、スイッチの形)
- VR での手の当たり判定の具合、音の大きさ

最初に動かしたときにエラーや見た目の崩れが出たら、コンソールの文面かスクリーンショットをもらえれば直します。

## 用意するもの

- VRChat Creator Companion(VCC)と、VCC が指定する版の Unity(2022.3 系)
- VCC で作った World のプロジェクト。VRChat SDK - Worlds は 3.7.4 以上(保存機能を使うため)。確認に使ったのは 3.9.0 です。

## 組み立て方

1. VCC で World のプロジェクトを新しく作り、Unity で開きます。
2. このリポジトリの `vrchat/Assets/KeyswitchCrusher` フォルダーを、Unity プロジェクトの `Assets` の下にコピーします。
3. 新しいシーンを作って保存します(File > New Scene)。
4. メニューの **Keyswitch Crusher > ワールドを組み立てる** を選びます。
   - 1 回目は Udon のプログラムを作るだけで終わります。コンソールにエラーが出ていないことを確かめて、もう一度同じメニューを選びます。
   - 2 回目で、部屋・スイッチ・看板・音・出現地点がシーンに置かれます。
5. 再生ボタンを押すと、Unity の中で試せます(ClientSim)。
6. VRChat SDK > Show Control Panel > Builder から、いつもどおりビルドとアップロードをします。

置き場所や大きさを変えたいときは、`Editor/KeyswitchCrusherBuilder.cs` の数字を直してもう一度メニューを選ぶと、作り直せます(シーンの「KeyswitchCrusher」を消して置き直します。手で動かしたものは元に戻ります)。

### 日本語のフォント

文字は Unity に入っているフォントで出します。Windows の VRChat では OS のフォントで日本語が補われますが、Quest(Android)では日本語が出ません。`Assets/KeyswitchCrusher/Font` フォルダーを作って日本語のフォント(.ttf か .otf。Noto Sans JP など、ワールドに入れてよいライセンスのもの)を入れてから組み立て直すと、そのフォントを使います。

## 遊び方

- **叩く**: 中央の大きなキーにレーザーを当ててトリガー(デスクトップはクリック)。VR では手を直接キーに突っ込んでも叩けます。デスクトップでは、キーに出ている文字と同じキーを押しても叩けます(スイッチの近くにいるとき)。
- **工具店(左の看板)**: 上のボタンで「工具」「技・自動破壊」「強化」を切り替え、行の右の「買う」で買います。「まとめ買い」を押すたびに ×1 → ×10 → ×100 → 全財産 と替わります。強化は、買えるもの、条件を満たしていないもの、習得済みの順に並びます。
- **記録の看板(右)**: 「実績」「統計」「軸」「周回」「音」を切り替えます。周回は取り消せないので、ボタンを 2 回押すと行われます。
- **金のキー**: ときどきスイッチの手前に金色の箱が 13 秒だけ現れます。レーザーで押すか、手で触ると取れます。

### ブラウザ版との違い

- 「キーボードで叩いた回数」は、デスクトップのキー入力と VR の手で叩いた回数を数えます。
- 絵文字のアイコンは出しません(フォントに入っていないため)。
- ワールドを離れている間は進みません(ブラウザ版も、タブを閉じている間は進みません)。
- W・A・S・D は移動にも使うので、その文字のキーが出ている間は、キーを押すと動きながら叩くことになります。

## ブラウザ版を変えたとき

工具・強化・実績・軸の表は、`index.html` から機械的に書き出しています。ブラウザ版の数字や名前を変えたら、次を実行してください。

```sh
node vrchat/tools/gendata.js          # KeyswitchCrusher.cs の表を書き換える
node vrchat/tools/export-audio.js     # 音を変えたときだけ。ffmpeg と Playwright が要る
```

計算のしかたそのもの(ダメージの式、周回の条件など)を変えたときは、`KeyswitchCrusher.cs` も同じように直します。

## 確かめ方

Unity がなくても動く試験が 2 つあります。どちらも Node.js と .NET SDK 8 が要ります。

```sh
sh vrchat/tools/difftest/run.sh    # ブラウザ版と VRChat 版に同じ操作を流し、状態が一致するかを比べる。保存と読み込みの往復も見る
sh vrchat/tools/udoncheck/run.sh   # スクリプトが呼ぶ命令が Udon で使えるかを、VRChat SDK を取り寄せて調べる
```

1 つ目は、叩く・待つ・買う・金のキー・周回を混ぜた操作(1 回およそ 6 万操作)を乱数で作り、ブラウザ版のスクリプトと VRChat 版のスクリプトの両方で実行して、1 操作ごとにスクラップ・耐久・所持数・強化・実績などを比べます。Unity と VRChat の部品は代用品に置き換えているので、比べているのは計算だけです。
