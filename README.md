# キースイッチ・クラッシャー

キーボードを 1 台ずつ壊していく、ブラウザで動くクリッカーゲームです。

## 遊び方

- キーは A→Z、つづいて 1→0 の順に 36 個並びます。画面のどこをクリック・タップしても叩けます(ショップと上のボタンを除く)。手元のキーボードでは、いま画面に出ているキーと同じキーを押すと叩けます。
- 与えたダメージがそのままスクラップになります。スクラップで工具・自動破壊・1 回かぎりの強化(工具の効果 2 倍など)を買います。
- ショップ上部の「まとめ買い」で、1 回に買う個数を ×1・×10・×100・全財産(買えるだけ)から選べます。
- 強化は全部で 160 個あります。工具ごとの効果 2 倍(6 段)のほか、キーボードを壊しきった台数や実績の数で強くなるもの、連打するほど威力が上がるものがあります。ショップの「強化一覧」で、習得済み・値段・解放の条件をまとめて見られます。
- 最初に使えるのは青軸だけです。キーボードを 1 台壊しきるたびに(周回をまたいで数えます)、赤軸・茶軸などほかの軸が 1 つ手に入り、選んで替えられます(違いは打鍵音と軸の色だけ)。
- ときどき「金のキー」が現れます。押すと、30 秒間すべてのダメージ 7 倍のフィーバーなどが起きます。
- キーボードを決まった台数まで壊しきると「周回」できます(1 回目は 8 台、周回するたびに 5 台ずつ増えます)。スクラップや工具を手放して最初からやり直す代わりに設計図を受け取り、1 枚につきすべてのダメージが永久に +5% されます。条件ぴったりで 3 枚、条件を超えて壊しきった 1 台ごとにさらに 1 枚もらえます。実績・軸・統計は残ります。
- 「音」で、全体・叩く音・自動破壊の音・壊れる音の音量をそれぞれ変えられます。
- 「統計」で、遊んだ時間や叩いた回数などの記録を見られます。
- 実績が 122 個あります。進み具合はブラウザに保存されます。

## 使い方

`index.html` をブラウザで開くだけで動きます。外部のライブラリや通信は使わず、このフォルダだけで完結しています。

## 音源

青軸・茶軸・赤軸・黒軸・銀軸の打鍵音は録音で、[The Listening Museum(sheets.works)](https://sheets.works/data-viz/keyboard-sounds)の音源集から取得しました。同ページによる出どころは次のとおりです。

- 青軸・茶軸・赤軸・黒軸: [Mechvibes](https://mechvibes.com) の同梱パック「CherryMX Blue / Brown / Red / Black - PBT keycaps」
- 銀軸: [keyboardsounds](https://github.com/nathan-fiscaletti/keyboardsounds)(GPL-3.0)の Cherry MX Speed Silver

そのほかの軸(桃・緑・紫・金・白)は、ブラウザ上で合成した音です。
